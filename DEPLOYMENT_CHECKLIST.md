# Deployment Checklist for ppaltsokas.com

Use this checklist as we proceed through the setup:

## Phase 1: Railway Domain Setup
- [ ] Railway Hobby plan active
- [ ] Custom domain added in Railway: `www.ppaltsokas.com`
- [ ] Railway provided DNS records (CNAME target copied)
- [ ] SSL certificate generated by Railway (shows as "Active")

## Phase 2: Namecheap DNS Configuration
- [ ] Logged into Namecheap account
- [ ] Opened DNS settings for ppaltsokas.com
- [ ] Added CNAME record: `www` → Railway CNAME target
- [ ] Configured root domain redirect (ppaltsokas.com → www.ppaltsokas.com)
- [ ] Saved DNS changes

## Phase 3: Backend Configuration
- [ ] Updated `ALLOWED_ORIGINS` in Cloud Run environment variables
- [ ] Included: `https://www.ppaltsokas.com,https://ppaltsokas.com`
- [ ] Backend deployed/updated with new CORS settings

## Phase 4: Frontend Configuration
- [ ] Updated `VITE_API_URL` in Railway variables
- [ ] Set to Cloud Run backend URL
- [ ] Railway redeployed frontend

## Phase 5: Verification
- [ ] DNS propagated (verified with nslookup or online tool)
- [ ] Domain loads: https://www.ppaltsokas.com
- [ ] SSL certificate active (padlock icon in browser)
- [ ] Frontend loads correctly
- [ ] Chatbot connects to backend
- [ ] No CORS errors in browser console
- [ ] Test message sent successfully

## Phase 6: Post-Deployment
- [ ] README.md updated with live domain
- [ ] All features tested
- [ ] Monitoring/logs checked
- [ ] Documentation updated
